# 셀러 순이익 계산기

일인 마켓 셀러용 순이익 계산 도구. 사입가, 플랫폼 수수료, 배송비, 기타비용을 입력하면
개당 순이익과 마진율을 실시간으로 보여준다. 빌드 과정 없이 `index.html`만 열면 바로 동작한다.

## 실행 방법

`index.html`을 브라우저로 열거나, 정적 파일 서버에 폴더째로 올리면 된다.

```bash
npx serve seller-calculator
```

모바일에서 열고 "홈 화면에 추가"를 하면 앱처럼 아이콘으로 실행할 수 있다.

## 기능

- 스마트스토어·쿠팡·에이블리·지그재그·브랜디·오늘의집·11번가 수수료율 프리셋 (탭 한 번으로 적용, 실제 계약 수수료로 직접 수정 가능)
- 판매가를 입력해 순이익을 계산하는 모드 / 목표 마진율을 입력해 권장 판매가를 역산하는 모드
- 손익분기 판매가 자동 계산
- 상품별 계산값 저장·불러오기 (브라우저 로컬 저장소, 서버 없음)

## 주의

수수료율 기본값은 참고용 추정치다. 카테고리·계약 등급에 따라 실제 수수료가 다르므로
정산 내역을 확인해서 값을 직접 수정해야 정확하다.
